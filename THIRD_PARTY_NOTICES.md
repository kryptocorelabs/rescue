# Third-party notices

The preview.4 ZIP contains its own `THIRD_PARTY_NOTICES.md`, locked Windows
Rust dependency inventory, Rust standard library notices, and original
notices for the self-contained .NET 10.0.14 runtime packs. Use the notices
from the exact archive when redistributing its contents.

The notices kept directly in this repository document the historical
preview.3 package with .NET 10.0.9. The
[application source](https://github.com/kryptocorelabs/apps-source) uses MIT
for first-party code. Dependencies retain their own terms.

Rescue does not bundle Tor. ClamAV is an optional external scanner, not part of this distribution.
