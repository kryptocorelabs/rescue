# KryptoCore Rescue 0.1.0-preview.4

Windows x64. Extract the ZIP and run KryptoCore-Rescue.exe. No separate .NET installation is needed.

- Authenticate KCV1 through KCV4 and export Vault logins to a new JSON file. Use the matching password or configured emergency credential. The input stays intact.
- Existing KCC extraction and optional sender verification remain available. Use a protected destination for plaintext and retain encrypted backups.
- The ZIP and its EXE match both Windows builds from [this Actions run](https://github.com/kryptocorelabs/apps-source/actions/runs/42690317991). The [source commit](https://github.com/kryptocorelabs/apps-source/tree/674ab7d708b010d76fd10f6f42dd03399c22b511) and both build records identify the tested binaries. The ZIP has a detached publisher signature. Windows Authenticode and independent audit are pending.
